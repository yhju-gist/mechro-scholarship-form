# 박사재학생 장학금 연구실적 접수 (GIST 기계로봇공학과)

**학생용 홈페이지:** https://yhju-gist.github.io/mechro-scholarship-form/
(영어 화면: https://yhju-gist.github.io/mechro-scholarship-form/?lang=en)

학생이 홈페이지에 논문·특허·수상 실적과 증빙 PDF를 내면, 담당자의 구글 시트 한 장에 모두 모입니다.

## 보안 구조
- **학생**: GIST 메일(@gist.ac.kr·@gm.gist.ac.kr)로 받은 6자리 인증번호로 본인 확인 → 본인 제출만 보고 고칠 수 있음. 학번과 메일은 1:1로 묶여 남의 학번으로 제출할 수 없음
- **담당자**: 홈페이지 맨 아래 '관리자' → 관리자 비밀번호(구글 서버에만 저장, 이 저장소에는 없음)
- 증빙은 진짜 PDF·JPG·PNG만 받음, 시트 수식 실행 차단, 업로드·인증 요청 횟수 제한
- 학생 자료(시트·증빙 폴더)는 담당자 구글 계정에만 있고 공유되지 않음

## 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 학생이 보는 홈페이지 (깃허브에서 바로 열림) |
| `scholarship_form.gs` | 접수 서버 — 담당자 구글 계정에 한 번 붙여 넣기 (시트·증빙 폴더 저장) |

## 담당자 설치 (처음 한 번, 약 10분)
1. 구글 드라이브에서 **새 스프레드시트**를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs` 내용을 모두 지우고 [`scholarship_form.gs`](scholarship_form.gs) 내용을 통째로 붙여 넣은 뒤 저장합니다.
3. 함수 `setup`을 고르고 **실행**한 뒤 권한(시트·드라이브·메일 보내기)을 허용합니다. 시트 탭 7개와 증빙 폴더가 생기고, 실행 로그에 관리자 비밀번호가 한 번 나옵니다.
   - 코드를 새 판으로 바꿨을 때도 `setup`을 한 번 더 실행하면 새 칸·설정 줄만 추가됩니다(기존 자료는 그대로).
   - (속도) 왼쪽 **서비스 +** → **Google Sheets API** 추가를 권장합니다. 시트를 한 번에 읽고 써서 제출이 몇 배 빨라집니다. 없어도 동작은 같습니다.
4. **배포 → 새 배포 → 웹 앱**을 고르고, 실행은 "나", 액세스는 "모든 사용자"로 정합니다. 나오는 주소(…/exec)를 복사합니다.
5. 이 저장소의 `index.html`에서 `const API = '';` 따옴표 안에 그 주소를 넣고 저장합니다. 그때부터 홈페이지에서 제출이 됩니다.
   - 주소를 넣기 전에는 홈페이지가 "미리보기"로만 열리고, 제출 버튼은 꺼져 있습니다.

## 운영
- 시트 **설정** 탭에서 평가명, 접수마감, 실적인정 기간, 지도교수 목록, 문의처, **문의 메일**(인증 메일 답장 주소), 허용 메일 도메인을 바꾸면 홈페이지에 바로 반영됩니다.
- 인증 메일은 담당자 구글 계정에서 나가며(하루 약 100통 한도), 학생이 답장하면 '문의 메일' 주소로 갑니다.
- 학생은 '논문 저자 표기 이름'(예: Gildong Hong)을 함께 적습니다 — Claude가 증빙의 저자 목록에서 본인을 찾을 때 씁니다.
- 같은 학번으로 다시 제출하면 마지막 제출만 반영됩니다(이전 제출은 '대체됨').
- 마감 후에는 Claude가 증빙(저자 수, FA·co-FA·CA·ETC, Accept일)과 JCR(최신판 카테고리 최고 순위, IF)을 확인해 시트를 채우고 RAWDATA 엑셀을 만듭니다. 학생 입력과 다른 것은 '더블체크' 시트에 모입니다.
