# 박사재학생 장학금 연구실적 접수 (GIST 기계로봇공학과)

**학생용 홈페이지:** https://yhju-gist.github.io/mechro-scholarship-form/
(영어 화면: https://yhju-gist.github.io/mechro-scholarship-form/?lang=en)

학생이 홈페이지에 논문·특허·수상 실적과 증빙 PDF를 내면, 담당자의 구글 시트 한 장에 모두 모입니다.

## 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 학생이 보는 홈페이지 (깃허브에서 바로 열림) |
| `scholarship_form.gs` | 접수 서버 — 담당자 구글 계정에 한 번 붙여 넣기 (시트·증빙 폴더 저장) |

## 담당자 설치 (처음 한 번, 약 10분)
1. 구글 드라이브에서 **새 스프레드시트**를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs` 내용을 모두 지우고 [`scholarship_form.gs`](scholarship_form.gs) 내용을 통째로 붙여 넣은 뒤 저장합니다.
3. 함수 `setup`을 고르고 **실행**한 뒤 권한을 허용합니다. 시트 탭 7개와 증빙 폴더가 생깁니다.
4. **배포 → 새 배포 → 웹 앱**을 고르고, 실행은 "나", 액세스는 "모든 사용자"로 정합니다. 나오는 주소(…/exec)를 복사합니다.
5. 이 저장소의 `index.html`에서 `const API = '';` 따옴표 안에 그 주소를 넣고 저장합니다. 그때부터 홈페이지에서 제출이 됩니다.
   - 주소를 넣기 전에는 홈페이지가 "미리보기"로만 열리고, 제출 버튼은 꺼져 있습니다.

## 운영
- 시트 **설정** 탭에서 평가명, 접수마감, 실적인정 기간, 지도교수 목록, 문의처를 바꾸면 홈페이지에 바로 반영됩니다.
- 같은 학번으로 다시 제출하면 마지막 제출만 반영됩니다(이전 제출은 '대체됨').
- 마감 후에는 Claude가 증빙(저자 수, FA·co-FA·CA·ETC)과 JCR(최신판 카테고리 최고 순위, IF)을 확인해 시트를 채우고 RAWDATA 엑셀을 만듭니다.
